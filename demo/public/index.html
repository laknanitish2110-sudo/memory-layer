The Solution

Memory that understands, not just remembers.

Memory Layer doesn't store chat logs. It builds understanding — who you are, how you learn, what frustrates you, and what you're working toward. Then any AI app can tap into that understanding.

🧠

Emotional Context

Tracks how you felt, not just what you said. "You were frustrated last time" changes how AI approaches you. That's empathy, not recall.

🌐

Cross-App

Works across ChatGPT, Claude, coding tools, tutors — any AI application. One memory, everywhere. Your tutor session informs your code assistant.

🔒

User-Owned

Like "Sign In with Google" but for AI memory. You control what apps access, delete, export, and port your data. The platforms don't own you.

⚡

Understanding, Not Data

contextForAI() returns compressed natural language — not 500 raw chat logs, but one paragraph that tells the AI who you are.

How It Works

Four lines to give your AI a memory.

Install the SDK, track interactions, set traits, and call contextForAI(). That's it. Your AI now knows who it's talking to.

// Install
npm install @memory-layer/core

// Set up
import { MemoryStore, UserProfile, InMemoryAdapter } from "@memory-layer/core";

const store = new MemoryStore({ appId: "my-app" });
const profile = new UserProfile(store, "user-123");
// Track how the user is doing, not just what they said
await profile.trackInteraction({
  topic: "recursion",
  sentiment: "frustrated",
  engagement: 0.3,
  frustrationTrigger: "abstract explanations without code",
});

// Set user traits — skills, preferences, goals
await profile.setTrait("learning_style", {
  category: "preference",
  value: "code examples first, theory second",
});

await profile.setTrait("python", {
  category: "skill",
  value: "Python",
  confidence: 0.35,
});
// In a DIFFERENT app — same user, shared memory
const codeAssistant = new MemoryStore({ appId: "code-assistant" });
const profile = new UserProfile(codeAssistant, "user-123");

// One call. One paragraph. Full understanding.
const context = await profile.contextForAI();

// Feed it to your AI prompt
const response = await llm.chat({
  system: `You are a coding assistant. Here is what you
know about the user:\n\n${context}`,
  messages: conversation,
});
contextForAI() returns:
"This user prefers code examples first, theory second. They are beginner at python and advanced at sql. They tend to get frustrated with abstract explanations without code. In their most recent session, they were frustrated. Recently they have been working on recursion. Their goals: deploy a Python API to production by end of month."

That's not a stat dump. That's understanding. One paragraph that changes how any AI talks to this user.
